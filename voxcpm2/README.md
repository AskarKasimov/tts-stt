# VoxCPM2 HTTP API

Исходники инференса [OpenBMB/VoxCPM](https://github.com/OpenBMB/VoxCPM),
исходный коммит `f772e498a45fbb5fb8e13fbf9b9c48be9fe33e69`.
Лицензия: [Apache-2.0](LICENSE).

Запуск, формат запроса и проверка без весов описаны в [API.md](API.md).
Обёртка использует `openbmb/VoxCPM2`, возвращает WAV и загружает модель
при первом запросе. Переменные окружения: `MODEL_ID` и `DEVICE`.
Для текста до 10 000 символов доступен `POST /synthesize`.

В репозитории оставлены библиотека инференса и тесты API, выбора устройства,
загрузки весов и безопасности. Gradio-демо, обучение, CLI, отдельный модуль
выравнивания таймкодов, примеры и альтернативное Docker-развёртывание удалены.
